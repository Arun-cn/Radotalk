# Radotalk

Radotalk is a Node.js Express application that provides a chat server using Socket.IO. It also includes user authentication and registration functionalities.

## Installation

1. Clone the repository:

   ```sh
   git clone https://github.com/Arun-cn/Radotalk.git
   cd Radotalk
   ```

2. Install dependencies:

   ```sh
   npm install
   ```

3. Create a `.env` file in the root directory and add the following environment variables:

   ```env
   MONGODB_URL=<your_mongodb_url>
   JWT_SECRET=<your_jwt_secret>
   ```

4. Start the server:
   ```sh
   npm start
   ```
